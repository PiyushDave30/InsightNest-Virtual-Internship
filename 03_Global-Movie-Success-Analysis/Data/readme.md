# Data

This section contains the datasets used in the **Global Movie Success Analysis** project, including the original Kaggle dataset and the cleaned, analysis-ready dataset prepared for analysis.

---

## Dataset Source

The project uses the **Global Movies Dataset (1950–2026)** obtained from Kaggle.

| Attribute | Details |
|---|---|
| Dataset | Global Movies Dataset |
| Source | Kaggle |
| Period | 1950–2026 |
| Records | 100,000 |
| Raw Dataset | 27 columns |
| Cleaned Dataset | 30 columns |
| Format | CSV |

[View Global Movies Dataset on Kaggle](https://www.kaggle.com/datasets/suhanigupta04/global-movies-dataset-19502026/data)
